# Stock Market Researcher

A personal stock-market research project that uses
[ankit02327/stock-price](https://github.com/ankit02327/stock-price)
as a source of stock-market data and project resources.

## Why this dependency exists

The project uses the `stock-price` repository as an upstream
data source. It is included as a Git submodule under:

vendor/stock-price

## What this project does

- Loads stock data from the upstream project
- Performs independent market analysis
- Generates research summaries
- Experiments with stock-market analytics

## Upstream project

- Repository: https://github.com/ankit02327/stock-price
- Upstream version: v0.1.8
